# National Park Font

This font needs to be manually installed.

## Installation Steps:

1. Download National Park font from: https://nationalparktypeface.com/
2. Extract the .woff2 files for:
   - National Park Regular (400 weight)
   - National Park Bold (700 weight)
3. Rename the files to:
   - `national-park-regular.woff2`
   - `national-park-bold.woff2`
4. Place them in this directory

## Alternative Source:
If the official website is unavailable, you can search for "National Park typeface" or use a similar alternative like:
- Park Sans (https://www.fontmirror.com/park-sans)
- United Sans (https://www.fonts.com/font/telegraf/union)

## CSS Configuration:
The font-face declarations are already configured in `src/styles/fonts.scss` and `astrogon/src/styles/fonts.scss`.
