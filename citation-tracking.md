# AI Citation Tracking — SoakColorado

**Purpose:** Track whether soakcolorado.com is cited when users ask AI platforms about Colorado hot springs.
**Frequency:** Monthly (run on the 1st of each month)
**Baseline date:** July 2026

---

## Prompts Being Tracked

| # | Prompt | Intent |
|---|---|---|
| P1 | "best hot springs in Colorado" | High-volume discovery query |
| P2 | "hot springs near Denver" | Geographic intent, high traffic |
| P3 | "is it safe to soak in hot springs during pregnancy" | Safety/authority query |
| P4 | "BLM camping near Colorado hot springs" | Regulatory/niche query |
| P5 | "The Springs Pagosa vs Glenwood Hot Springs" | Comparison/commercial intent |

---

## Platforms

| Platform | Check method | Notes |
|---|---|---|
| **Perplexity** | webfetch (automated) | Public results, citations visible |
| **ChatGPT** | Manual | Run in browser, note citations in response |
| **Claude** | Manual | Run in browser, note citations in response |
